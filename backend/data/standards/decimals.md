# Georgia Standards of Excellence (MGSE) — Decimals

## Grade 5
### MGSE5.NBT.7
Add, subtract, multiply, and divide decimals to hundredths, using concrete models or drawings and strategies based on place value, properties of operations, and/or the relationship between addition and subtraction.
- Relate the strategy to a written method and explain the reasoning used.
- Key concepts: aligning decimal points, placeholder zeros, place value regrouping.

## Grade 6
### MGSE6.NS.3
Fluently add, subtract, multiply, and divide multi-digit decimals using the standard algorithm for each operation.
- Decimal operations in multi-step word problems.
- Key concepts: standard division algorithm with decimals, estimating products.
