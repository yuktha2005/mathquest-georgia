# Georgia Standards of Excellence (MGSE) — Decimals

## Grade 5
### MGSE5.NBT.3
Read, write, and compare decimals to the thousandths place using base-ten numerals, number names, and expanded form.
- Summary: Understand that each place value to the right of the decimal point represents a tenth, hundredth, or thousandth of a unit. Compare decimals by lining up digits by place value from left to right.
- Key concepts: tenths, hundredths, thousandths, place value, inequality symbols (<, >, =).

### MGSE5.NBT.7
Add, subtract, multiply, and divide decimals to hundredths using concrete models or drawings and strategies based on place value and properties of operations.
- Summary: When adding and subtracting decimals, strictly align the decimal points so place values match, and use placeholder zeros where needed. When multiplying, multiply as whole numbers and place the decimal point by counting total decimal places in both factors.
- Key concepts: aligning decimal points, placeholder zeros, regrouping across the decimal, multiplying decimal digits.
- Formula/Rule: Align decimal points for +/-; for multiplication, total decimal places in product equals sum of decimal places in factors.

## Grade 6
### MGSE6.NS.3
Fluently add, subtract, multiply, and divide multi-digit decimals using the standard algorithm for each operation.
- Summary: Perform rapid, accurate calculations with multi-digit decimals in multi-step real-world problems (such as money, measurements, and scientific calculations). In division, shift the divisor's decimal point to make it a whole number and shift the dividend's decimal point the exact same number of places before dividing.
- Key concepts: standard long division algorithm with decimals, shifting decimal point in divisor, estimating products and quotients.
- Formula/Rule: Divisor * 10^k and Dividend * 10^k ensures an integer divisor.
